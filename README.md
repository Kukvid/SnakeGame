# Игра «Змейка»

В ходе учебной практики была разработана игра «Змейка» на языке Python.

Видео игрового процесса: <https://rutube.ru/video/91d2e77ba41289c3a53ef05b43367869/>

## Описание игры

Основной игровой процесс заключается в направлении движения змейки с целью поедания еды и последующего заполнения змейкой всего поля, но стоит быть осторожным по отношению к бомбам и препятствиям.

В игре присутствуют различные объекты, с которыми можно взаимодействовать, меню и звуковое сопровождение игрового процесса.

- главное меню позволяет попасть в настройки и выбор режима, начать прохождение или выйти из приложения;
- в настройках можно изменить размер поля, сложность, режим игры и громкость внутриигровых звуков;
- перед началом игры запускается стартовый экран с приветствием и правилами;
- блоки появляются после каждого второго подобранного яблока, столкновение с ними завершает игру;
- бомбы при касании со змеёй делают её в два раза короче;
- после смерти изображение змеи изменяется;
- при поедании яблока змейка становится больше;
- на экране отображается длина змейки и рекордная длина за всё время игры.

## Правила

1. Цель игры — есть красные яблоки.
2. Чем больше яблок съедено, тем длиннее становится змея.
3. Если змейка врезается в себя или в стену, игра завершается.
4. В зависимости от выбранного режима встречаются препятствия и бомбы: препятствия действуют как стены, а бомба уменьшает змейку вдвое.

Игра завершается, когда игрок взрывается на бомбе, играя за змейку, состоящую из одного блока, врезается в блоки, стены или самого себя либо заполняет змейкой всё поле.

## Управление

Стрелки вверх и вниз служат для движения по кнопкам меню, стрелки влево и вправо позволяют изменить параметры игры, `Enter` позволяет сделать выбор, `Esc` возвращает пользователя в предыдущее меню.

Управление в игре осуществляется с помощью клавиш:

- стрелки меняют направление движения змеи;
- `Space` скрывает экран с правилами и запускает игру снова после поражения или победы;
- `Esc` после поражения или выигрыша возвращает в главное меню.

## Запуск

В папке `dist` находится файл `snake.exe`. Достаточно два раза нажать левой кнопкой мыши по ярлыку или по `snake.exe`, после чего запустится главное меню игры.

Также можно скачать весь репозиторий и запустить файл `main.py`.

```cmd
python main.py
```

## Технологии и результат

Использование языка программирования Python и библиотек `pygame`, `pygame_menu` и `pyinstaller` позволило создать игровое приложение. Упаковка игры в исполняемый файл `.exe` обеспечивает удобство распространения и запуска на компьютерах без необходимости установки дополнительного программного обеспечения.

В процессе разработки создано игровое меню, позволяющее выбрать размер поля, режим игры, громкость звуков и сложность игры. В игру внедрены бомбы, которые укорачивают змейку вдвое, и блоки, которые становятся преградой для змейки.

Дальнейшее развитие проекта может включать добавление новых функций и режимов игры, улучшение графического интерфейса, добавление скинов для змейки, возможность создания таблицы рекордов для разных игроков, оптимизацию алгоритмов и введение музыкального сопровождения.
